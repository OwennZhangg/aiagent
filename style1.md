# Quick Reel Style Guide

## Overview

The video style is a **fast-paced talking-head explainer**.

The creator remains the main visual throughout most of the video. Supporting images, screenshots, graphics, and short text overlays are added around or above the creator to reinforce specific points.

The video should feel fast and visually active without requiring a completely new full-screen scene for every sentence.

---

## Core Structure

Plan the video as a sequence of **short script beats**, not traditional cinematic scenes.

Each beat should:

- communicate one clear idea
- usually last around 1–3 seconds
- contain a short piece of script
- decide whether a supporting visual is actually needed
- transition quickly into the next idea

Typical flow:

Hook  
→ Talking head + supporting visual  
→ Talking head + different visual  
→ Talking head only  
→ Talking head + screenshot/image  
→ Talking head + another visual  
→ Talking head only  
→ Payoff / conclusion  
→ Short CTA if needed

---

## Hook

The video should begin immediately.

Do not use:

- greetings
- introductions
- unnecessary context
- slow setup

The first 1–2 seconds should create curiosity using something like:

- a strong claim
- a surprising fact
- a question
- a problem
- a contradiction

The viewer should quickly understand why they should keep watching.

---

## Script Style

The script should be:

- fast
- conversational
- concise
- easy to say naturally
- broken into short sentences
- focused on one idea at a time

Avoid long explanations when the same idea can be communicated in fewer words.

Each script beat should naturally lead into the next one.

---

## Creator / Talking Head

Assume the creator will film **one continuous talking-head recording**.

The creator should remain visible for most of the video.

Editing should primarily add supporting elements around the creator rather than constantly replacing them with full-screen B-roll.

Some parts of the video should intentionally contain only the creator.

These clean sections prevent the video from becoming visually overcrowded.

---

## Supporting Visuals

Do NOT force a picture into every beat.

For every beat, ask:

1. What is being said?
2. What is the purpose of this statement?
3. Would a visual make this easier to understand or more interesting?
4. If yes, what visual would best reinforce it?

Useful supporting visuals include:

- photographs
- screenshots
- website screenshots
- product images
- diagrams
- charts
- logos
- historical images
- interface screenshots
- examples of whatever is being discussed

Prefer concrete visuals directly related to the spoken statement.

### Example

Script:

> "SQL lets you retrieve information from a database."

Good visual:

> Screenshot of a SQL query beside a database table.

Bad visual:

> Generic picture of someone using a computer.

---
